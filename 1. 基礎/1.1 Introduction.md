## 什麼是 git
> 有的人會說是版本管控, 有的人會說是備份   
> 又或是說 兩個都是.....  
> 這個問題, 我認為在我使用的過程中  確實是有影響了我   
> 簡單說, Git 幫你記住「專案曾經長什麼樣子」

<br><br>
  

## 首先是安裝 
> 安裝步驟我就先跳過, 畢竟網上一抓一大把   
> 這邊主要用 **Git Bash**, 因為 Git UI 我用不慣 XD   
> 裝好後可用 `git --version` 指令確認是否安裝成功

<br><br>


## 開始用之前, 先有的觀念
> **本地就有紀錄** — 版本可以先存在你的電腦, 不一定要連網   
> `**.git` 資料夾** — 初始化後會出現, 裡面是 Git 的全部紀錄, **不可以刪除**   
> **三個區域** — ① 你改檔案的地方 ② 決定這次要存哪些變更 ③ 真正存放版本歷史的地方   
> **commit** — 就是存下一個版本快照, 之後可以回溯
> 細節見 **2. 觀念**

<br><br>
  

## 為什麼要先設定 name / email
> 每次版本紀錄都會署名, 之後才看得懂是誰改的   
> 建議在開始 commit 之前先設好:
> 可用 `git config --list` 檢查是否設定成功   
```
git config --global user.name "Wade"
git config --global user.email "Wade@Wade.Wade"
git config --list
```

<br><br>


## Git 不是 GitHub
> **Git** 是你電腦上的版控工具   
> **GitHub** 是把 repo 放在網路上, 方便備份與跟別人協作的平台   
> 兩個不一樣, 但常常會一起用   但很多人會把這兩個搞混
